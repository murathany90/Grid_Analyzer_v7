# v7.5 numerical fidelity validation — 29 September 2026

**FINAL GATES: FAIL — BRANCH LOCAL/PUSHED, NOT MERGED.** The source fixes and synthetic checks pass, but both allowed full-model runs returned the local-PV baseline after the integrated station-control Newton solve failed. A sub-30-second fallback is not an integrated success. The package version remains `7.4.0` while this gate is open.

The old report names this same workbook but does not store its hash; historical accuracy comparisons therefore have filename provenance rather than a two-sided workbook hash proof.
- `baseline.Q` and `model.qSpec` are both **net bus MVAr**. When actuator buses become PQ, their specification is set to solved `baseline.Q`, and only the difference from the original net specification is allocated to owned units. Thus `Q0_bus = Qbaseline_bus` and `Qbus = Q0_bus + Σ(Ki ΔQctrl)`. A fixture with a fixed load on an actuator bus confirms that the load is not counted twice. Real-model unallocated ownership Q was about `1.14e-12 MVAr`.
- The station-limit loop now uses `controllerChanged` for each controller and `anyControllerChanged` only to request another solve. The two-controller fixture confirms that saturation of one controller leaves the other's target, status, and participation intact. The four-restart bound remains unchanged.
- Newton's Armijo test now scales its sufficient-decrease requirement by the capped step actually applied. A small-step regression covers the mathematical defect. Run #2 shows that this was **not** the full-model blocker.

## Jacobian and transformer audit

The 5-bus directional finite-difference fixture covers Va, Vm, control ΔQ, a fixed remote Vm, and a two-actuator Q column. It differentiates `G = calc − spec`; Newton solves `J dx = spec − calc`. Maximum relative directional error was **`2.59e-8`** over Va-only, Vm-only, ΔQ-only, and mixed directions.

The primary `20260928_0900_SN1_TR0` export has **3,684** `TypTr2` and **3,684** `ElmTr2` rows. `tr2cn_h/tr2cn_l` pairs are `YN/YN: 2,844`, `YN/D: 826`, `D/YN: 8`, and `D/D: 6`; their marginal counts are high side `YN: 3,670`, `D: 14`, low side `YN: 2,852`, `D: 832`. The 23 `TypTr2` columns contain no explicit clock, phase, `phitr`, `nt2ag`, or `nt2ph`. All 3,684 `bushv`/`buslv` pairs resolve through `StaCubic` to different `ElmTerm`s, and every high-side nominal voltage exceeds its low-side voltage. Thus the HV→LV orientation is measured, but the clock number and PowerFactory angle-sign convention remain **UNVERIFIED (U15)**. `Transformer2W.phase` stays `0`; no vector-group angle was inferred from `YN/D` alone.

Topology in both runs remained two islands: one solved main island and one `NO_REFERENCE` island.

Run #1 failed at integrated Newton iteration 8 with `NR_LINE_SEARCH_FAILED` and returned baseline. Run #2 failed at the same iteration, with `93,054.68 MW` maximum mismatch, `stepCap=0.16394`, and `bestNormRatio=Infinity`. The latter means every tested candidate was rejected by the solver's voltage bounds before its residual could be evaluated. This is a state/feasibility or active-set issue; **`LINEAR_SOLVE_FAILED` did not occur**, so the conditional linear-solver investigation and ordering changes were not triggered. The Armijo change did not alter the failure stage. No third large-model run was made.
