# SLD development

## 2026-10-16: solved loads and unique ideal-switch flows

Full AC snapshots now carry optional `loads` and `switchFlows` result arrays. Preparation retains immutable source load FIDs and each island's actual solver index. The final result mapper emits load consumption P/Q only after convergence with a valid solved voltage, using the solver's final active-balance correction and the exact eligible positive-load weights already used in preparation. Fixed and negative loads retain their modeled signed constant-PQ equations. Model P0/Q0 are separately identified. No ZIP law is inferred: the current engine's unsupported `loadVoltageDependency` setting produces an explicit unavailable load result when requested. Out-of-service, open-cubicle, unsolved and failed cases never substitute dispatch.

Switch reconstruction is a post-solve native-terminal KCL audit. It accounts for native branch endpoint powers (including transformer magnetizing power), solved load/generator/external-grid injections, modeled international transfers and voltage-dependent shunt admittances. Only bridges of the actual closed ideal-switch multigraph with complete native injections and a residual within the configured nodal tolerance get signed FROM/TO P/Q. Parallel paths and cycles have a free circulation and remain `SWITCH_FLOW_UNAVAILABLE`; no pseudoinverse, equal split or reduced-bus net-injection estimate is used. Open/off switches and unproven cubicle order remain unavailable. Numeric solver equations, canonical connections and maneuvers are unchanged.

SLD reads `ElmLod|FID` or a proved interbar feeder's unique real breaker (lone selector if appropriate). Status/reason and result/model provenance are accessible in the source tooltip. Comparison uses two independently valid snapshots; absent old-format results explicitly require recalculation. New unit/browser checks cover actual Full AC-to-SVG values, scenario edits/deltas, signed loads, eligibility weights, unsupported voltage dependence, reversed contacts, parallel cycles, bridge cuts, missing injection records, residual rejection and stale identity. Fresh SN3/SN4 real cases and FID ledgers stay private under `local-benchmark-results/lf-load-switch`.

Source identity matters: local SN3 maps Adatoprakpınar B8820 to LB188 (P0 −16.448 MW, Q0 8.06 MVAr); SN4 maps it to LB187 (P0 −13.33 MW, Q0 5.80 MVAr). The requested LB189/B8820/−33.04/+6.60 combination is absent from these supplied local models; no FID or input is rewritten to match it.

## Current architecture and boundaries

The application SLD is always a full station. Feeder/equipment selection, focus, opposite station and winding navigation, history, voltage/YTM filters, scenario maneuvers, seven presentation layers and results/details remain on that sheet. It is a derived read-only view, not a network editor. The renderer and its viewport/geometry caches have no bay/regional scope transitions; lower-level physical geometry helpers retain independent regression coverage.

DGS catalog → `CanonicalNetwork` → `buildStationTopologyGraph` → source audit → immutable `sldDrawingGraph` → `connectedStationLayout` / `stationOverviewPage` → `SvgSldRenderer`. `physical-layout.ts` owns presentation, not electrical connectivity. `electrical-topology` and effective scenario networks own conductivity. Selection uses source class/FID across map, inventory and analyses. Delayed raw-source responses are gated by model hash.

Source switch visibility has three explicit classes. `DRAW_VERIFIED_PATH` retains verified devices and open/parallel/bypass/coupler circuits. `HIDE_NONFUNCTIONAL_SOURCE_LEAF` removes only independently evidenced dead-end branches from the drawing projection, including all wire/node/icon remnants; original sources, canonical network, switch states and scenarios remain intact. `REVIEW_UNRESOLVED` retains ambiguous devices and blocks unproved batch operations. The source audit panel exposes both FIDs, cubicle ownership, classification, reason and raw evidence. A single proven StaSwitch belongs to its actual equipment lead; multiple cubicle devices require documented order, never a guessed iorder sequence.

Feeder operations use the verified source main circuit and real DS–CB–DS devices; alternate selectors/bypasses and hidden leaves cannot enter the command set. Individual and feeder maneuvers use existing local scenario commands, including restore and optional Full AC. B0 is immutable; changes invalidate old results. No physical equipment command is transmitted.

## Analysis and UI contracts

The SLD adds no LF/DC/N1/SC equations. Result overlays require exact model, scenario, calculation type/engine/version/options, settings and source/control identities. Stale or absent results display STALE/NOT_RUN with no invented numbers. N1 manual/hybrid owner, BASE/POST/CHANGE and current case identity remain authoritative. DC supports P screening, not fabricated Q/U/I or Full AC. SC supports existing calculated-network approximations; IEC 60909-0:2016 normative acceptance and PF parity remain blocked/unverified, with Ip/Ib/Ith null where unsupported. No old result fallback may bypass these gates.

LF FROM and TO arrows use their respective native terminal P injections, never TO = −FROM. P/Q loss uses both native ends. Unknown capacity is not zero loading. Nominal voltage and angle-reference mismatches suppress corresponding values. Units are MW/MVAr/A/kV and loading-change pp. Generator P/Q/control/Q limits and raw TypTr2 ratings/taps remain separate from operating bus values.

The one physical horizontal toolbar exposes YTM, station, seven view layers, voltage, palette, values/arrows, feeder selection, history, readable/fit/zoom/focus, SVG/PNG, information and fullscreen. It scrolls horizontally at narrow widths and never wraps. The side panel starts closed, contains feeder operations and detailed source audit, and preserves selection when closed. Full station SVG export uses the saved fit bounds, independent of pan/zoom. PNG consumes that same self-contained SVG, paints white, preserves Unicode and uses bounded whole-page scaling (2× preferred; max 16,384 side / 32 MP with explicit reduction warning). Object URLs are revoked; failures are visible.
