# v7.0.2 stabilization

Continues `4b5ee3dee39c503d02461aa1d348b87914fd62b7` on
`feature/v7-architecture-migration`. CanonicalNetwork, immutable Raw DGS,
workers, result identity/comparability and numerical solvers remain intact.

- Energization is one history operation. Source rollback removes only its
  introduced terminal/switch changes, preserves later explicit edits, and
  retains prerequisites still used by another energization operation.
- Base calculation uses an empty overlay without deleting the active scenario.
  Base/scenario calculation actions are explicit; display role is independent.
- Map line details share scenario/result stores and expose direct service,
  calculate, source rollback, results and SLD actions. Canvas P/Q styles retain
  voltage families; V summarizes all matching station buses. Delta offers
  P/Q/V/loading with comparable results only. Missing values stay unavailable.
- Engineering and raw CSV use typed numeric values, decimal commas without
  grouping or rounding, UTF-8 BOM, `sep=;`, semicolon delimiters and text formula
  protection. Semantic column headings include muted source field names.
- Station SLD defaults to all feeders across all voltage levels, with dynamic
  width, source selector/switch paths, transformer bridges and shared internal
  terminal connections. SVG download clones the full logical fit box and
  preserves the on-screen viewport. Feeder-detail selection remains paged.
- JSON/ZIP selection runs locally. Bundled fflate inflates only the selected
  JSON in chunks, after reading the bounded ZIP directory. One JSON loads
  automatically; multiple JSONs offer a size-labelled selection dialog.
  Guards cover unsafe paths, CRC, declared/actual size, compression ratio and
  entry count. Limits: 512 MiB input/selected JSON, 2 GiB total declared size,
  1,000 entries, 4 MiB directory, compression ratio 1,000. Encrypted, split and
  ZIP64 archives are unsupported; ordinary stored/deflated ZIPs are supported.
- Four persistent offline basemap styles use cached vector paths, independent
  of network/results/selection/flow layers. The 81-province geometry and coast
  share the central WGS84 projection. Attribution and data licensing are in
  [BASEMAP-LICENSE.md](../src/map/BASEMAP-LICENSE.md).
