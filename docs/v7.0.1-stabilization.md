# v7.0.1 stabilization

This update preserves Raw DGS → CanonicalNetwork → ScenarioOverlay →
AnalysisEngine → ResultStore → UI. Full NR and other numerical kernels are unchanged.

- A multi-terminal bus action creates one scenario revision/history entry,
  invalidation and notification; one undo restores all member terminals.
- Shared voltage bands: ≥300, ≥180, ≥100, >36 and positive ≤36 kV. These are
  filter buckets; true source nominal voltage remains visible.
- New settings use v6.8 thresholds 50/65/80/100 and widths 3/2/1.4. Existing
  localStorage preferences are retained. Delta colors are configurable.
- Scenario comparison retains P/Q, loading, active/reactive losses and bus
  voltage/angle differences. Missing or unmatched values remain unavailable.
- Inventory and all seven operating categories share class/field metadata,
  indexed parent/terminal/type context, name-first rows and engineering/raw CSV.
  Unknown classes and fields remain accessible without invented semantics.
- A pure StationTopologyGraph drives station, feeder and regional SLD views.
  Overview uses horizontal busbars, vertical paged feeders and transformer
  bridges. Feeder detail follows source switches; internal nodes are collapsed
  in overview. Selection, scenario actions, pan/zoom/fit and SVG use shared state.
- Both `control1` JSON snapshots were removed from Git tracking with
  `git rm --cached`; local files remain. Ignore rules and lint/CI guard new model
  JSON. The obsolete LFS full-model workflow was removed. Historical Git/LFS
  objects may still exist; history was not rewritten.

portable builds pass. The portable output remains a self-contained HTML file.

H2525 leaves the reference island at 4,115 solve buses (one pre-existing
unsupplied bus), the same slack and 5,191 branches instead of 5,192. No
zero-degree PV/PQ bus or branch impedance below 1e-8 pu appears in that island.
The initial 7,779-state Jacobian has finite entries and no ILU pivot at its
existing clamp. Failure occurs before any Q-limit update; the last successful
linear solve reports relative residual 9.17e-9. The failed iterate's pivots,
residual and condition number are not exposed by the solver, so these initial
diagnostics do not prove nonsingularity at failure. No safe root-cause fix was
proven in the bounded inspection. No tolerances, regularization, loads or
Q-limit controls were changed. The 16:00 model was not rerun.
