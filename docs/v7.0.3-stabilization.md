# v7.0.3 UI stabilization

Continues `f97048f88e784f9ee65c3b7fa053bc59042e5e2b` on
`feature/v7-architecture-migration`. Numerical solvers, ZIP loading and the
offline Türkiye basemap are unchanged.

- Lightning results use explicit fixed column widths and an exact detail-row
  colspan. Row expansion preserves column and footer positions and the table's
  scroll offset. Details are compact; technical IDs remain secondary.
- Every meaningful numeric/header metric sorts the filtered complete dataset
  before pagination. First click sorts descending, second ascending. Power
  columns sort by absolute MW/MVAr, other numbers numerically, names with
  Turkish collation, and unavailable values last in either direction.
- Bus rows show both solver pu and calculated kV (`vnKv × vmPu`), leaving
  unavailable voltages blank.
- Map hover/selection text follows nominal, loading, P, Q, V and selected
  scenario-delta metric. A configurable diverging delta scale encodes both
  sign and magnitude; scenario off/on colors take priority. The legend names
  the active physical quantity. Delta table signs are textual as well as colored.
- SLD retains TM General, explicit Feeder/Bay and Regional views. The empty
  legacy bay list, 12-item feeder-picker pager, duplicate service/fit controls,
  obsolete CSS and unused state/helpers are removed. Regional paging remains;
  one searchable feeder picker contains all available feeders. Source-derived
  connectivity, scenario state, selection, voltage filters, zoom/pan and SVG
  export are preserved.

## Validation

Typecheck, architecture lint, 43/43 tests (39 retained plus 4 targeted),
standard build and portable build pass. Portable HTML is regenerated.

Browser smoke with the small fixture covered base/scenario AC, Lightning
headers and row expansion at 1280×720 and 1920×1080, sorting across pages,
bus pu/kV, delta Q/loading detail and legend, delta table signs, and TM,
Feeder/Bay and Regional SLD transitions. Direct pointer clicks retained
`scrollTop`, `scrollLeft`, column widths and footer position; horizontal
overflow was zero in both viewports. Technical SLD redraw retained zoom.

One 143 MB real-model load in the portable app completed in 5.02 s; one base
Full AC converged in 13 iterations / 14.58 s. Lightning showed 2,382 lines
and 4,115 buses; row expansion, complete-dataset loading sort and V kV were
checked. No H2525 scenario calculation was run. The existing
`LINEAR_SOLVER_FAILED` limitation remains.

The real-model TM overview still shows MİSLİOVA's 23 source feeders and
ÇAYIRHAN's 34, with full logical view boxes `3295×950` and `3658×1962`.
