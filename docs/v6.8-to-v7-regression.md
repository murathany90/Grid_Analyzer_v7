# v6.8 to v7 regression acceptance

This is the acceptance checklist for migrating the v6.8 browser application to
the v7 modules. Feature scope comes from [the v6.8 feature inventory](v6.8-feature-inventory.md).
The small DGS fixture at `tests/fixtures/small-dgs.json` is deterministic and
contains two voltage levels, connected 400/154 kV equipment, source and load
devices, an out-of-service line, station coordinates, and 15 line rows.

Observed acceptance evidence: 26 unit/regression tests, typecheck, architecture lint, standard and portable builds pass locally. Browser observations are in [browser-validation.json](validation/browser-validation.json). CI is checked against the final PR head separately.

## Recorded v6.8 observations

The source inspection identified these behaviors for explicit regression review:

- The blank-map clearing preference does not disable the earlier unconditional
  click listener.
- Filtering by YTM or voltage can leave a selected line bound to details after
  the line disappears from the visible scope.
- The legacy DC path does not select a scenario for transformer-only or
  bus-only overrides.
- Loading a model can restore the v6.5 title through the compatibility wrapper.

These observations are described in the feature inventory; this checklist does
not assume they have been fixed or accepted in v7.
