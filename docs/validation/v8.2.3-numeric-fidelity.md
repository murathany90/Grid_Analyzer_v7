ControlContext verifies source `usetp`, `i_ctrl`, `selBus`, `imode`, `qsetp`, `iQorient`, `rembar`, `cpCtrlNode`, member controlled node references, ordered `psym/cvqq`, and signed droop fields against the DGS model. Every SN4 `cpCtrlNode`, `controlledHVNode`, and `controlledLVNode` reference matches its controller `rembar` FID. Controller Q allocations use owned generators; non-owned injections remain in nodal KCL. The remaining Q discrepancy is concentrated on controller-owned generators. The 223 signed-droop controllers remain unsupported.

The main numerical improvement comes from carrying the monotonic Q-limit active set into warm-start NR solves, including the Q-limited external-grid reference. Final P corrections now use the typed `maxFinalActiveBalanceCorrections` bound and a tighter inner solve. Extending station rounds from 12 to 16 reduced the unresolved count and improved all six canonical KPIs. A joint P/Q trial and longer standalone control runs were measured and reverted because they worsened the operating point or left more unresolved controls. A common P/Q/control equilibrium has **not** been established for SN4.
