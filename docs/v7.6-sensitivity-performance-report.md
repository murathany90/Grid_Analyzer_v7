## Formulation and Armijo

**FORMULATION_EQUIVALENCE = PASS.** The independent four-bus dense P/PQV reference and production augmented solve agree within `1e-7` for Vm, Va, actuator Q, remote Vm, remote P/Q residual and network power balance. The off-solution Schur/elimination test shows that removing the actuator Q row with its nonzero controlDq column yields the same residual/Jacobian direction as explicit P/PQV. A five-bus fixture shows the additional Q-sharing relation retained with two actuators. Thus the E1–E3 conclusion in `V7.5_FORMULATION_ROOT_CAUSE_AND_RECOMMENDATION.md` that the single-actuator formulation is *reversed* is **REJECTED**. This does not establish global convergence of the direct integrated method.

The v7.5 Armijo change was checked algebraically. Before it, sufficient decrease used `baseNorm × (1 − 1e−5 × scale)` despite a capped step. It now uses `baseNorm × (1 − 1e−5 × stepCap × scale)`, the actual applied fraction. For `stepCap < 1` the former demanded a larger decrease than the step warranted. The unit test covers this difference; v7.5's real run still rejected all candidates before residual evaluation. No new Armijo tuning was made. Direct integrated remains selectable as `INTEGRATED_EXPERIMENTAL`; line-search failures now record largest Vm, angle and controlDq steps with IDs, old Vm range and first invalid candidate.

## Agent findings and decisions

1. **Formulation:** elimination and dense-reference tests agree with P/PQV for one actuator; rejected the “reversed formulation” claim; no core rewrite, preserving the existing physics.
2. **Multi-actuator:** elimination retains Q-sharing; kept that constraint explicit in the equivalence test; avoided claiming that independent P buses are identical.
3. **Ordering:** synthetic RCM improved bandwidth and iterations, but the one real run had 124 high-residual RHS versus 78 historical controller failures; reverted production default to natural while retaining RCM as an explicit option. The comparison uses different failure populations, so it does not quantify an exact per-RHS regression.
4. **Pivot:** both real matrices had clean raw pivots near 0.192 with no regularization; did not add symbolic-structure-breaking row swaps; no evidence pivoting addresses the failure.
5. **Solver:** all 201 RHS reached ILU2-BiCGSTAB and only 77 passed the unchanged `1e−6` true-residual check; retained tolerance and strict acceptance.
6. **Controller accounting:** 34 successful second-pass RHS were conservatively rolled back after another ownership change; corrected their diagnostic label in final code; no fabricated active controller result.
7. **Provenance:** the converged fallback is explicitly disqualified; no accuracy gate is marked passed from it.
8. **Performance:** 66.5 s RHS work alone defeats 30 s; stopped tuning after the single model run and kept the full diagnostics for a later sparse-solver design.

**PROMPT_ASSUMPTION_REJECTED:** RCM is a safe production optimization for this model. **EVIDENCE:** synthetic benefit did not transfer to the real RHS residual and controller gates. **REPLACEMENT:** natural ordering as default, RCM selectable for research.

**STOP_REASON:** the measured RHS work alone exceeds the full 30 s budget, and all controllers rolled back. **RECOMMENDED_ARCHITECTURE:** investigate a robust sparse solve with reusable factorization or multi-RHS strategy and explicit true-residual verification on captured synthetic matrices before another capped real-model experiment. Also revisit the conservative ownership reclassification state machine separately. No pivot or tolerance change is justified by this run.
