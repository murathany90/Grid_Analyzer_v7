# v7.9 dense controller consistency — single-run decision

**Decision: FAIL — NOT MERGED.** The only real-model C run used commit `7be03a235ba8e8a3f4846d7d9193cdbeb005b669`, source `20260928_0900_SN1_TR0.zip`, and the same PowerFactory reference workbook as v7.8. The Full AC solve took **12,564.65 ms**, accepted **zero** Q rounds, returned `BASELINE_FALLBACK`, and had voltage MAE **0.016959 pu**. All three are independent failures of the v7.9 production gates (`<10,000 ms`, accepted rounds `>0` with nonfallback provenance, and V MAE `<=0.0071 pu`). No second model run was made.

## Hypothesis, evidence, decision

| Hypothesis | Evidence | Decision |
| --- | --- | --- |
| Dense and acceptance objectives differ | v7.8 source solved only `free × free` residuals, while proposal and trial measured all active residuals. | Dense least squares now uses all active rows and free Q columns; exact fixed Q effects are subtracted from every row. |
| Fixed controllers can re-enter through a stale raw delta | v7.8 source left saturated entries in `rawDeltas` after moving them to `fixedMoves`. | Fixed allocations are single-owned, removed from free deltas, and included once in the trial; trust rejection recomputes the dense direction. |
| Independent coordinate gradient steps overshoot when columns correlate | v7.8 gradient candidate predicted 0.424099 pu RMS from 0.023999 pu RMS. | One common global gradient line minimizer gives a predicted 0.010586 pu RMS on the real model, but its Full NR trial failed line search. |
| These corrections suffice for production | The single v7.9 run accepted no Q round and exceeded the time and voltage gates. | **Rejected.** Stop numerical tuning in this task and preserve the branch for review. |

Three targeted synthetic tests cover the 5-row/3-free-column objective with two fixed effects, fixed/free Q ownership, and global descent with correlated columns. The existing small physical station-control tests still pass. These tests do not prove real-model acceptance.
