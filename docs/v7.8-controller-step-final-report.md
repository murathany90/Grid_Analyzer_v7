## Implemented and verified before the model run

The controller code now rebuilds an applied Q proposal and its predicted residual at each trust fraction, preserves the coupled direction by common scaling rather than clipping every column independently, and checks predicted descent before invoking Full NR. If the coupled proposal is non-descent, it evaluates a directionally feasible gradient proposal. An exact physical bus-Q signature prevents a previously trialed Q vector from entering Full NR again. A sensitivity refresh occurs only after an accepted operating-point change. The after-acceptance participation filter excludes units at either Q bound from unrestricted weights, with directionally available units retained when needed. KLU and its `1e-6` true-residual criterion are unchanged.

A 128-controller synthetic matrix demonstrated the prior independent clipping failure: the unconstrained coupled solution reduces residual, but separate clipping reverses descent; common scaling preserves descent and smaller trust gives a smaller Q vector. Other focused tests proved the non-descent callback is not invoked, Q-bound participation is correct, and a small physical fixture accepts a bounded Q step while reducing its remote-voltage error.
